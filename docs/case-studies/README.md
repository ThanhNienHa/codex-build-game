# Case studies

Case studies document real use of `$build-game` without publishing proprietary source, assets, credentials, local paths, or personal data.

Each case should include:

- date, engine/version, stage, and selected process mode;
- anonymized task and scope;
- artifacts inspected and actions guided by the skill;
- fresh automated and playable evidence;
- honest verdict and remaining limitations;
- concrete improvements proposed for the skill.

Use `template.md` for new reports. Do not convert historical claims into fresh evidence. If Preview or playtesting was not rerun, state that explicitly.
